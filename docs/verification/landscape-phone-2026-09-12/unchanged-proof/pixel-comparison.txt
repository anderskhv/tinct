Did portrait, tablet and desktop change?

Every surface was rendered on origin/main (baseline-origin-main/) and again
with this branch applied (after-change/, plus repeat captures). For each
screenshot this is the smallest pixel difference found against the baseline
across the repeat captures of the changed build.

Repeat captures are needed because several of these surfaces are not
deterministic from one run to the next on the SAME build: the voice orb is a
live canvas animation, the entry hero runs a light/cover animation, and the
book page fades a cover in. Two captures of one identical build differ in 13
of these 56 files. PNG bytes are not stable either, so file hashes are not a
useful test; pixels are.
