# The Divine Comedy — Source

**Author:** Dante Alighieri
**Translator:** Henry Wadsworth Longfellow (1807-1882)
**Original publication:** 1867

## Project Gutenberg Sources

- Inferno: https://www.gutenberg.org/ebooks/1001 (eBook #1001)
- Purgatorio: https://www.gutenberg.org/ebooks/1002 (eBook #1002)
- Paradiso: https://www.gutenberg.org/ebooks/1003 (eBook #1003)

All three released August 1, 1997. Most recently updated October 29, 2024.

## Notes

- Longfellow's translation preserves Dante's tercet (terzina) structure: three-line stanzas
- Each stanza is treated as one paragraph in the edition JSON
- The Appendix (six sonnets by Longfellow about the Comedy) was stripped from Paradiso
- Table of Contents and Gutenberg boilerplate removed from all three parts
- 100 cantos total: Inferno (34), Purgatorio (33), Paradiso (33)
