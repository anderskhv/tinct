# Symposium successor: shared terminology (all renderers)

The assessors found recurring Jowett words whose modern sense has shifted. Render them the same way everywhere. Keep Plato's argument intact: where an argument turns on a word, use the same modern word at every step.

|---|---|---|

## Quotation marks in the paragraphs you render

- Straight single quotes for speech.
- A speech that runs over several paragraphs opens a quote at the start of each paragraph and closes it only where the speech ends.
- A nested quotation inside speech uses straight double quotes.
- Restore any quote marks the current text dropped, where their loss breaks the sentence. Examples: 'necessarily' at 7.14; "good" at 7.50.
- Do not change quotation marks in KEEP or PROTECTED paragraphs.
