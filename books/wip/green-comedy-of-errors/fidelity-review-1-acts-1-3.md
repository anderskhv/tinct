## Defects found

**Ch3 p41 — non-blocking addition.** Source: *"...and no man that hath a
name / By falsehood and corruption doth it shame."* Candidate: *"And no man
with a good name shames it through dishonesty and corruption — **and yet so
it goes.**"* The clause "and yet so it goes" is an interpretive gloss not
licensed by the source — it makes explicit an irony (Adriana's husband
*is* shaming his name) that the source leaves the audience to infer from
context. Not a fidelity-breaking error (it doesn't reverse or invent a
claim, just underlines one), but it is an addition and should be trimmed to
match the source's restraint. **Non-blocking; recommend removing "and yet so
it goes."**

**Ch6 p68 — minor semantic drift, non-blocking.** Source: *"there's no man
is so vain / That would refuse so fair an offer'd chain."* Candidate: *"no
man is so **silly** as to refuse such a fine offered chain."* "Vain"
(foolish/self-regarding) softened to "silly" — close enough in sense that
this does not change the claim, but "vain" carries a slightly different
character judgment (excessive self-regard vs. simple foolishness) than
"silly." **Non-blocking; optional word-choice note only.**
