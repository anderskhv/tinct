# Character proposal — not runtime data

`proposal.json` supplies editorial identities and draft card copy. Its sourceChapters identify source locations for review, not exhaustive appearances or verified mention offsets. The proposed IDs are new, book-scoped identities; no existing runtime IDs are replaced.

The current runtime character package is edition-specific, hash-pinned and uses normalised UTF-16 offsets. This proposal deliberately supplies no offsets or claim of runtime compatibility. Integration must derive mentions from the final accepted texts, review ambiguous aliases and bind each included edition to its exact hash. The five completed modern chapters do not justify whole-book mention coverage.

Use opening-safe descriptions in onboarding. Later revelations—Lucy’s changed state, the driver’s identity, the child in the final NOTE—need appropriate spoiler treatment. Mina’s name change does not create a new character; Arthur’s inherited title requires chronology; the two Quinceys are different people. The Count’s historical ancestors and Castle Dracula must not become present-day Count mentions.

Unlisted minor characters remain in the text. A complete mention review can propose additional cards, including the unnamed captain, Mr. Swales and Sister Agatha, without inventing names or expanding their roles.
