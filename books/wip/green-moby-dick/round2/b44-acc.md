## Verdicts

- **Ch 44 — The Chart:** Clear and well modernized. 4 small fixes: 44.2 ("not this particular night" misreads as a negation), 44.8 hyphen consistency ("feeding-grounds"), 44.9 "double Cape Horn" → "round", 44.11 closing Prometheus sentence has broken syntax that defeats read-aloud.
- **Ch 45 — The Affidavit:** Good. The glosses (Season-on-the-Line, spoke/hailed, heave down, brit, Propontis) work well. 3 fixes: 45.0 opening clause does not parse, 45.4 "Chilian" → "Chilean" (edition uses Chilean elsewhere), 45.19 three-dash clause obscures which phrase names Wafer's book.
- **Ch 46 — Surmises:** Dense but readable, as intended. 1 fix: 46.1 "kept on for some object remote and blank in the pursuit".
- **Ch 47 — The Mat-Maker:** Good. 2 fixes: 47.1 "prescribed to by both ... has the last, shaping blow at", 47.12 inverted "So looks the long line ...".

## Questions for the lead (not proposed as changes)

1. **45.5 "New Zealand Tom"** vs **45.4 "New Zealand Jack"** (and "Timor Tom"). This reads as an internal contradiction. I believe it is Melville's own slip in the 1851 text; if so, keep it (do not correct Melville). Please confirm against source.
2. **44.10 "...like a white-bearded Mufti in the crowded thoroughfares of Constantinople? Yes."** A listener may hear "Yes" as agreeing that the idea is mad, whereas the next sentence argues the whale is recognizable. I left it because any clarification risks adding interpretation. Fidelity reviewer: does the source's "Yes" sit the same way?
3. **Unglossed terms left alone** because context carries them: "marline" (47.1), "cranes", "mainyard was backed" (47.12), "samphire baskets" (47.12), "Mufti" (44.10), "Levanter/Simoon" (44.9). Add a gloss only if the lead wants one. A possible accurate gloss is "marline (thin tarred cord)".
4. **45.10 "forswearing the sea"**: I kept it because it is still current English. "Swearing off the sea" would be plainer if the lead prefers.
