## Questions for the lead

1. **16.49–16.50, "Does thee?" / "I does":** this keeps Quaker grammar, against the brief's rule to modernize Quaker speech. I left it because Ishmael's unconscious mimicry is the joke, and modernizing it would lose the humor. Please confirm this is an accepted exception.
2. **"parmacetty" (16.24) and "parmacetti" (19.22):**
   - Is this spelling difference in the source? If it is, keep both. If not, make them consistent.
   - Neither is glossed. A first-time reader may not see that it means the sperm whale. I did not add a gloss because the word sits in dialogue, and a gloss would be awkward there. The lead may want one in the chapter's narration.
3. **16.2, "Devil-dam" / "Devil-Dam":** the ship's name is capitalized differently within one paragraph. If the source prints it both ways, it stays under decision 3. If not, normalize it to "Devil-dam".
4. **22.13, Watts hymn:** the four verse lines are run together on one line, separated only by capitals. The brief says to keep verse lines as the source lays them out. Please check that against source.json. I could not check it because this review reads only the candidate text.
5. **22.0, "Stubb, the second mate and her brother-in-law":** this is correct as written. I note it only because a reader may stumble on Charity being related to Stubb. It is not a defect.
