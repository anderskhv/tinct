## Method

1. **Served text.** I read `app/public/data/editions/{book}-{original-en,modern-en,modern-da}.json`. The Federalist Papers is the only one of these four books that is also sharded. I compared all 85 shards (`editions-chapters/federalist-papers-{edition}/ch0001…ch0085.json`) against the whole-book files paragraph by paragraph and found **0 mismatches** in all three editions. In each of the four books, all three editions have the same paragraph count in every chapter, so a paragraph missing from one edition is missing from the same slot in the others.
2. **Sources.** I fetched every source myself with a generic User-Agent. After stripping the BOM and converting CRLF line endings, the repo raw files are identical to the current Project Gutenberg (PG) files:
   - `federalist-papers/raw.txt` = PG #1404
   - `second-treatise/raw.txt` = PG #7370

   - `us-founding-documents/raw-declaration.txt` = PG #1

   Line numbers below are PG file line numbers.
3. **Full diffs.** For each PG source I split the text into blank-line-separated blocks and compared them with the served original-en. I normalised quotes and whitespace; for Locke I also removed the `Sect. n.` prefixes and the `<i>`, `/#` and `#/` markers. I ran the check in both directions: every source block must appear in the served text, and every served paragraph must match a source block.
4. **Phrase searches.** I searched all three editions for at least three distinctive phrases from each missing passage. For modern-en I also searched keywords, because it paraphrases the original. For modern-da I checked only structure: paragraph counts and the positions of proper names.
5. **Second copies:**

   - Locke: the Wikisource transcription of the scanned 1764 London edition, which is the edition PG #7370 reproduces.
   - Rousseau:
